# Orbital-Motion-Simulator
A Python-based animator and simulator for planetary motion that visualizes celestial mechanics using numerical methods like Euler and Beeman integration. This tool allows users to study and analyze the dynamics of planetary systems through customizable simulations and visually engaging animations.

## How to Run the Code
To run the simulator, ensure you have Python installed on your system. Follow these steps:

1. Open a terminal and navigate to the project's root directory.
2. Run the following command:
   ```bash
   python run.py
